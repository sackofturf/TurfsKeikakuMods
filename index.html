Installation

How to install mods

BepInEx

You need BepInEx

All mods will be loaded with BepInEx. Its simple to use, and makes installing mods simple. You only have to do this step once, and then you can install any mods that use BepInEx.

  1. 1
    Download BepInEx

    Download BepInEx for Windows x64.

  2. 2
    Open your Keikaku folder

    In Steam, right-click Keikaku and choose Manage, then Browse local files.

  3. 3
    Extract BepInEx

    Drag and drop the contents of the BepInEx ZIP into the folder containing Keikaku Demo.exe.

  4. 4
    Start the game once

    Open the game and close it again after reaching the main menu. BepInEx is now ready for mods.

Mods

Installing individual mods

With BepInEx installed, this step is literally drag and drop.

  1. 1
    Download the release ZIP

    Choose the ZIP download on the mod’s page.

  2. 2
    Extract it into the game folder

    Drag and drop the content of the ZIP folder into where BepInEx is installed in your Keikaku folder.

  3. 3
    Start the game

    The mod will load automatically through BepInEx. Instruction on how to use the mod in game are on each mods dedicated page.

Mod

Keikaku Paint

Preview and save independent exterior-panel colours and surface finishes from inside Keikaku Demo.

Download

Download the latest release of Turf's Keikaku Paint here!

Download ZIP

What this mod does

  • Paint individual panels Paint the whole car or individual panels.
  • Preview changes live See colour changes as you change colours in the picker.
  • Choose a finish Solid paint and carbon fibre are the only supported finishes right now.

How to use this mod

Start the game and press F8. Choose a panel, adjust its colour or finish, then save when you are happy.
